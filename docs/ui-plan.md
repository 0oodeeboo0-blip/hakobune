# 段階 2: 基本の画面の進め方

デザイン案（claude.ai の Artifact「Hakobune メイン画面」）に合わせて、WinUI 3 で作る。
見た目・機能・使い勝手の判断は任せてもらっている。

## 決めたこと

- アクセント色は青緑（ライト #0B6E78、ダークでは明るめ）。行の高さは標準 34px、設定でコンパクト 28px。接続先の一覧は最初は開いた状態。
- 画面の文言は日本語。失敗の理由の日本語の説明は Core 側にまとめて、テストできるようにする。
- 設定の保存先は `%APPDATA%\Hakobune\`（接続先、送信待ち、設定）。パスワードは Windows の資格情報マネージャー。
- 画面用の接続は `RemoteBrowser`、転送は `TransferScheduler`。画面からサーバーを直接触らない。
- 画面の動き（ViewModel）は `Hakobune.Presentation`（WinUI に依存しない）に置き、Linux の CI でテストする。WinUI のアプリは XAML と Windows に固有の部分だけにする。
- 見本モード（`--demo`）は、デザイン案と同じ中身を本物の ViewModel に流し込む。CI は `--screenshot` でアプリ自身に画面写真を撮らせ、`screenshots` ブランチに置く。
- 接続先は `%APPDATA%\Hakobune\connections.json`、信頼したサーバーの鍵と証明書は `trusted-keys.json`（SSH の known_hosts にあたる）。
  パスワードは資格情報マネージャー（`Hakobune:{接続先の ID}`）。資格情報マネージャーが使えなくても接続は止めない（聞き直すだけ）。
- 左の接続先はクリックで接続する。右クリックで 接続・切断・編集・複製・削除。接続中に別の接続先を選ぶと、前の接続はやめる。
- 初めての SFTP の鍵は指紋を `SHA256:…`（`ssh-keygen -l` と同じ形）で見せて確かめる。鍵が変わったときは強く注意し、Enter では信頼しない。
  FTPS は Windows が信頼する証明書ならそのまま通し、自己署名などは指紋を見せて確かめる。
- クイック接続（URL を指定した接続。`--connect URL` でも使える）は保存しない。左の「クイック接続」に置き、右クリックの「接続先として保存…」で保存できる。
  URL のパスワードはアプリを閉じるまで覚えておき、保存すると決めたときだけ資格情報マネージャーに移す。
- 設定（左下の「設定」）は変えるとすぐ反映して保存する（「保存」ボタンは置かない）。画面の色（Windows に合わせる・ライト・ダーク）、
  一覧の行を詰める（コンパクト）、隠しファイルを表示する。保存の場所とバージョン（ビルドしたコミットつき）も出す。
  `settings.json` には前回の画面の様子（ウインドウの位置と大きさ・最大化、パソコン側のフォルダ、接続先の一覧と転送の一覧の開閉）も入れる。
  前回の場所が今の画面に見えなければ（画面を外したときなど）、真ん中に出す。
- ライト・ダークはウインドウの中身の RequestedTheme で切り替える（Application の色は起動のあとで変えられない）。
  ダイアログは画面の外側に出るので、出すときに画面の色を渡す。コードで作る部品の色は、App.xaml の Style（ThemeResource）で決める。
- サーバー側の属性は、どの方式でも ls と同じ「-rw-r--r--」の形で出す（MLSD の UNIX.mode や SFTP の属性からも作る）。
- ログは下の一覧の「ログ」タブ（「表示」メニューからも開ける）。接続・切断・接続の失敗、ファイルの操作、1 件ずつの転送の結果、
  やり直し、全部終わったときのまとめ、一覧の取り直しの失敗を、日本語で書く。「通信の詳細も出す」で、FTP のコマンドとサーバーの返事
  （FluentFTP のログ。パスワードは伏せる）と、SFTP の操作も出す。新しいものから 20,000 行まで覚える（`ActivityLog`）。
  コピー（Ctrl+C。選んだ行、なければ全部）、テキストファイルに保存、消す。いちばん下を見ているときは、新しい行についていく。
- 転送の一覧（とログ）の高さは、ファイルの一覧との境目を上下にドラッグして変える（境目を選んで ↑↓ でも）。高さは設定に残す。
- 「表示」メニュー: 隠しファイル、行を詰める、接続先の一覧、転送の一覧、ログ、設定。
- 一覧を取り直したときは、行を作り直さない（変わっていない行はそのまま使い、選択とスクロールの位置も残す）。
  WinUI の ListView の出入りの動き（行が縮んでまた広がる）は付けない。転送の一覧とログも同じ。
- 取り直しで増えた・変わった行だけを、うすい青緑で約 3 秒光らせて消す（段階 2 の確認で、デザイン案の 3 案から利用者が「案B」を選んだ）。
  開いたばかりのフォルダや別のフォルダでは光らせない。光の形は、選んだ行の背景と同じ（行の内側に左右 4・上下 2、角丸 4）。
  ハイコントラストでは光らせない。光っている時間は `FilePaneViewModel.HighlightDuration`、動きは `RowGlow`。
- 送らないファイル（段階 3）: 設定に名前の一覧（はじめは Thumbs.db、desktop.ini、.DS_Store、.git/、node_modules/、~$*、*.tmp）。
  * と ? が使え、最後が / ならフォルダ（中身ごと）。/ で始まる名前と途中に / がある名前は、送るフォルダからの位置で比べる。大文字と小文字は区別しない。
  アップロード（選んだものとフォルダの中）と同期で除き、ログに「送らないファイル N 件を除きました」と出す。同期でサーバーから消すときも、当てはまるものは消さない。
  パソコン側の一覧では、当てはまる行の名前を薄くし「送らない」の印を付ける。接続先ごとの名前は、接続先の編集の「詳しい設定」で足す（1 行に 1 つ）。
  設定の画面では、パソコン側でいま開いているフォルダに当てはめて、何が除かれるかを見せる（2 万件まで）。
- 同期（段階 3）: ツールバーの「同期」から「変わったファイルだけ送る（パソコン → サーバー）」か「受け取る（サーバー → パソコン）」を選ぶ。
  左右でいま開いているフォルダどうしを、名前・大きさ・更新日時で比べる（中身は読まない）。比べている様子と結果は確認のダイアログに出し、
  送るもの（新規・更新・空のフォルダ）だけを決定のボタン（「6 件を送る」）で送信待ちに入れる。ふつうの転送と同じく、やり直しも続きからの再開も効く。
  - 大きさが違い送り先のほうが新しいもの（向こうで直したのかもしれない）は、既定では送らない。「これも送る」で送る。
  - 送り先にだけあるものは、既定では残す。アップロードのときだけ「サーバーからも消す」を選べ、消すのは送り終えたあと（送信待ちの最後）。
    消すものを選ぶと、Enter で決まらないようにし、「元に戻せません」と出す。受け取るときは、パソコンのものを消さない。
  - 同じ名前でファイルとフォルダ（またはリンク）が違うものは送らない。リンクはたどらず、比べず、消さない。
    大文字と小文字だけが違う名前（Index.html と index.html）は、大文字と小文字を区別しないサーバーでは同じファイルなので消さない。
  - 時刻の細かさの違いを許す: 秒まで分かれば 2 秒、分まで（FTP の LIST）なら 61 秒の違いまで同じとみなす。日付まで（半年より前の LIST）なら大きさだけで比べる。
    FTP の LIST の時刻がサーバーの地域の時刻のまま届くときは、大きさが同じファイルの半分より多くで同じ時差（15 分刻み）なら、それを時計のずれとみなして直す。
  - いちばん上のフォルダを読めなければ、理由を出して比べない。中のフォルダを読めなければ、そこは何もしない（補足に出す）。20 万件で止める。
  - サーバーの一覧は画面用の接続で取る（転送用の接続には触らない）。比べている途中でパスワードや鍵を聞くことになったら、確認のダイアログをいったん隠して先に聞く。
- 控えと元に戻す（段階 3）: サーバーのファイルを上書き・削除する前と、受け取ってパソコンのファイルを上書きする前に、元のファイルを
  %LOCALAPPDATA%\Hakobune\backups に残す（設定で切れる。既定は 30 日・1 GB まで、1 つ 100 MB より大きいファイルは取らない）。
  - 転送で上書き・削除するときは、転送用の接続で受け取ってから上書き・削除する（`ITransferBackups`。続きから送り直すときは取り直さない）。
    右のパネルで消すときは、画面用の接続で受け取ってから消す。控えを取れなかったら消さない（設定で切れば、控えを取らずに消せる）。
  - 下の一覧の「控え」（ログの隣）に、いまの接続先の控えを操作（同期 1 回・アップロード 1 回・削除 1 回）ごとにまとめて新しい順に出す。
    1 つずつでも、操作ごとまとめてでも元に戻せる。サーバーのものは控えの写しを送信待ちに入れて送り直す（いまの中身は、上書きの前にまた控えに回る）。
    控えを取ったあとにサーバーで変わっていたら（上書きしたあとに大きさが変わった、消したあとに同じ名前ができた）、確認で知らせる。
  - 送信待ちの完了の行とログに「控えあり」と出す。同期の確認と削除の確認でも、控えを取ることを伝える。
- 方式の既定は「自動」（FFFTP と同じく選ばなくてよい）。暗号化（FTPS・明示的）を先に試し、サーバーが AUTH TLS を断ったときだけ暗号化なしの FTP でつなぐ。
  つながった方式は接続先に保存し、次からはその方式だけを使う（暗号化できたサーバーで、暗号化なしに戻ることはない）。
  ftp:// の URL（クイック接続）も「自動」。ロリポップ！のように暗号化しないと入れないサーバーへ「FTP（暗号化なし）」で入ろうとして断られたら、
  理由と一緒に「FTPS（明示的）でつなぎ直す」ボタンを出す（押すと方式を変えて保存し、つなぎ直す）。

## 作る順番

1. **骨組みと画面写真**: MVVM（CommunityToolkit.Mvvm）、メイン画面の配置を見本のデータで表示する「見本モード」（`--demo`）。
   CI でライト・ダークの画面写真を撮り、`screenshots` ブランチで確かめながら見た目を詰める。
2. **2 画面**: パソコン側（System.IO）とサーバー側（`RemoteBrowser`）。パンくず、絞り込み、並べ替え、フォルダの移動、F5、Backspace。
   一覧の更新に失敗したら、前回の一覧を残したまま InfoBar で知らせる。
3. **接続**: クイック接続と、接続先の保存・管理（FTP / FTPS / SFTP、文字コード、パッシブモード）。初めての SFTP の鍵と FTPS の証明書は確認画面を出す。
   CI では、Windows の上で動かした FTP サーバー（pyftpdlib）にアプリから実際に接続し、日本語のファイル名が並ぶことを画面写真で確かめる。
   秘密鍵にパスフレーズが掛かっていれば聞く（保存せず、アプリを閉じるまで覚えておく）。クイック接続は Ctrl+Q（FFFTP と同じ）。
4. **転送の一覧**: 下の一覧（すべて・進行中・待機中・完了・失敗）を `TransferScheduler` につなぐ。進み具合、速さ、残り時間、「失敗分を再送」、送信待ちの保存と再開。
   接続先ごとに `TransferController` を作る（自分の接続で送る。画面用の接続は使わない）。加えるとすぐ送り、すべて一時停止・再開、
   1 件ずつ取り消し・送り直し・今すぐ再試行。送信待ちは `%APPDATA%\Hakobune\queues\{接続先の ID}.json` に 5 秒ごとと切断のときに保存し、
   次に同じ接続先につなぐと、止めた状態で戻す（「前回の残りが N 件あります」）。転送中に切断・別の接続先・閉じるときは、止めてよいか聞く。
   CI では、Windows の上の FTP サーバーへアプリからフォルダを送り（`--upload`）、全部のファイルの中身が同じか確かめる。
5. **操作**: アップロード・ダウンロード（ボタン、ドラッグ＆ドロップ、エクスプローラーから）、新しいフォルダ、名前の変更、削除、属性の変更。
   アップロード・ダウンロードのボタンと Ctrl+U・Ctrl+D はできた。フォルダは中をたどって同じ形で送る。
   送り先に同じ名前があれば 1 回だけ聞く（新しいときだけ上書き・すべて上書き・送らない）。送り終わったら、開いているフォルダの一覧を取り直す。
   ドラッグ＆ドロップ: パソコン側からサーバー側へ落とすとアップロード、その逆はダウンロード。エクスプローラーからサーバー側か転送の一覧へ落としてもアップロード。
   選ぶ: クリック・Ctrl・Shift のほか、マウスで囲んで選べる（エクスプローラーと同じく、名前やアイコンを掴むとファイルのドラッグ、
   行の空いている所や一覧の下の空白から引くと枠。Ctrl を押しながらなら今の選択に足す。上下の端の外まで引くと一覧が流れる。空白を押すだけなら選択を外す）。
   CI では、本物のマウスの操作（囲む・端の外まで引く・名前を掴んでドラッグ）で確かめ、見出しの「N 個を選択」で数も見る。
   新しいフォルダ（Ctrl+K）、名前の変更（F2・Ctrl+N）、削除（Delete。パソコン側はごみ箱へ。サーバー側は元に戻せないので Enter では消さない）、
   属性の変更（Ctrl+T。チェックと数字のどちらでも）。サーバーの操作は画面用の接続で行い、転送用の接続には触らない。
   空のフォルダも送り先に作る（転送の一覧に「フォルダを作成」として並ぶ）。残り: サーバーからエクスプローラーへのドラッグ。
6. **仕上げ**: キーボード操作（FFFTP と同じ）、ファイルの種類のアイコン、ダークモードの確認、拡大率 100〜200% の確認、ログ。
   設定の画面と、前回の画面の様子に戻すこと、ログはできた。
