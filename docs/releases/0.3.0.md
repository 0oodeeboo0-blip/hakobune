Hakobune の最初の配布版です（段階 3 まで）。FFFTP の代わりに使える、FTP / FTPS / SFTP のファイル転送アプリです。

## できること

- パソコン側とサーバー側の 2 つの一覧で、アップロード・ダウンロード（ボタン、ドラッグ＆ドロップ、エクスプローラーから）。フォルダごと送れます。
- 送信待ちは、つながりが切れてもその場でやり直し、最後まで届けます。止めた分は、次に接続したときに続きから送れます。
- **変わったファイルだけ送る（同期）**: 新しい・変わったものだけを送り、確認の画面で中身を見てから始めます。
- **送らないファイル**: Thumbs.db や .git などを、送らないようにできます。
- **控えと元に戻す**: 上書き・削除の前に元のファイルを残し、下の「控え」から元に戻せます。
- **FFFTP から読み込む**: FFFTP の接続先（パスワードも）を読み込めます。
- 転送が終わったら Windows の通知でお知らせし、転送中はタスクバーに進み具合を出します。
- 一覧はマウスで囲んで選べます。列の幅も変えられます。

## 使い方

1. 下の「Assets」から `Hakobune-0.3.0-win-x64.zip` をダウンロードし、好きな場所に展開します。
2. 展開したフォルダの `Hakobune.exe` を開きます（インストールは要りません。Windows 10 / 11 の 64 ビット版で動きます）。

- 初めて開くときに「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください（このアプリには署名をしていないためです）。
- 前の版から入れ替えるときは、前の版を閉じてから、フォルダごと新しいものに置き換えてください。
  接続先・設定・送信待ちは `%APPDATA%\Hakobune`、控えは `%LOCALAPPDATA%\Hakobune\backups` にあるので、そのまま引き継がれます。
- 新しい版が出ると、アプリの下のステータスバーでお知らせします（設定の「お知らせ」で切れます）。
