## 使い方

1. 下の「Assets」から `Hakobune-（版）-win-x64.zip` をダウンロードし、好きな場所に展開します。
2. 展開したフォルダの `Hakobune.exe` を開きます（インストールは要りません。Windows 10 / 11 の 64 ビット版で動きます）。

- 初めて開くときに「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください（このアプリには署名をしていないためです）。
- 前の版から入れ替えるときは、前の版を閉じてから、フォルダごと新しいものに置き換えてください。
  接続先・設定・送信待ちは `%APPDATA%\Hakobune`、控えは `%LOCALAPPDATA%\Hakobune\backups` にあるので、そのまま引き継がれます。
- 新しい版が出ると、アプリの下のステータスバーでお知らせします（設定の「お知らせ」で切れます）。
